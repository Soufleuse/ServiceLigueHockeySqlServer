# ServiceLigueHockeySqlServer

Un API REST pour lire des données d'une ligue de hockey. Les données sont sur une
base de donnée SQL Server.


## Description

C'est un example de mes habiletés à coder des API REST en C# avec une base de
donnée SQL Server. Au moment d'écrire ces lignes, la plupart des API ont été
codées ainsi qu'un DockerFile pour conteneuriser l'application et des migrations
EntityFramework. Des tests unitaires sont en court de codage et devraient être
 isibles sous peu.

## Guide de démarrage

### Dépendences

* .Net 8.0
* SQL Server (testé sur la version 2022)
* Tout système d'exploitation qui peut rouler .Net 8.0 et SQL Server (testé sur
  Windows 10/11 et sur Debian/Ubuntu)

### Installation

* Le code peut être cloné du repo.
* À l'origine, une installation a été faite sous Apache installé sur Ubuntu, mais
  c'est suggéré d'y aller avec l'image Docker.

### Execution du programme

Le programme roule en construisant et en exécutant l'image Docker.
