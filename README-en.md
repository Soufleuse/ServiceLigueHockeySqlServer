# ServiceLigueHockeySqlServer

REST API for reading data from an hockey league, where data is stored in a SQL Server
database.

## Description

This is an example of my skills to code REST API in C# with a SQL Server database
storing the data. At the moment of writing, most of the APIs have been coded
alongside a Dockerfile to make these API conteneurized and Entity Framework migrations.
Some unit tests areunder way of coding and should be visible in a foreseable future.

## Getting Started

### Dependencies

* .Net 8.0
* SQL Server (2022 tested)
* Any OS that can run .Net 8.0 and SQL Server (Windows 10/11 and Debian/Ubuntu tested)

### Installing

* The code can be cloned from the repo.
* Originally, an installation was made under Apache on Ubuntu, but it is best to go
  with the Docker image.

### Executing program

The program is running by building and running the Docker image.
